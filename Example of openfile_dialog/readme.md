# C# File Handling

## Description
A C# Windows Forms project for reading, saving, and displaying text files.

## Features
- **Open:** Reads file data into a ListBox.
- **Save:** Saves user input.
- **Append:** Adds new data without deleting old data.
- **Clear:** Clears TextBox and ListBox.

## Assignment Question
**Can multiple inputs be saved at once?**

Yes. Set `Multiline = True` in the TextBox to enter multiple lines and save them together. Otherwise, only the latest input is saved.
