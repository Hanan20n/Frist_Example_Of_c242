## 2. Course Objectives

By the end of this course, students should be able to:

- Understand the fundamentals of C# programming.
- Apply programming logic and problem-solving techniques.
- Understand event-driven programming.
- Develop graphical user interface (GUI) applications.
- Work with methods, arrays, lists, and files.
- Connect C# applications to databases.
- Develop desktop applications.

## 4. Learning Outcomes

After completing this course, students should be able to:

- Understand Windows programming and event-driven applications.
- Develop GUI applications using Windows Forms.
- Apply programming logic to solve problems.
- Use C# programming structures correctly.
- Organize code using methods.
- Work with arrays and lists.
- Connect applications to databases using ADO.NET.
- Develop small- to medium-sized Windows applications.

## 7. Course Project

Students will develop a desktop application at the end of the semester.

The project should demonstrate concepts learned during the course, including:

- User interface design
- Variables and data types
- Decision structures
- Loops
- Methods
- Arrays or lists
- Database connectivity
- ADO.NET
- Desktop application development
